# Brief overview
This project contains a Network and Distributed Systems project, that has the following configured:
- static IP
- dynamic IP
- gateway
- DHCP server
- DNS server
- static routing
- dynamic routing using RIP 2
- website accessible from anywhere in the network
- wireless router
- NAT configuration

# How to run
In order to run and text this project, you will need to install Cisco Packet Tracer. Then, simply open the project and everything should run smoothly.
